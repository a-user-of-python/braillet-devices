# Braillet Devices

Hardware designs for **Braillet**, the electronic braille translator:
pop-in/out braille blocks that each hold a word or phrase and talk to an
ESP32-based reader, which shows the words as text.

This repository holds the physical side of the project:

- **boards/** — circuit board designs (schematics, PCB layouts, production files)
- **parts/** — mechanical and electronic part designs (blocks, dot pins, plates, case)
